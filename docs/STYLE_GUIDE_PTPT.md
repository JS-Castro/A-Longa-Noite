# Style Guide PT-PT

## Regra Base

Todo o conteudo textual deve ser escrito em portugues europeu.

## Preferencias

- usar "equipa", nao "time"
- usar "ficheiro", nao "arquivo"
- usar "jogador" e "sobrevivente" de forma consistente
- privilegiar frases diretas, tensas e contidas
- evitar tom excessivamente informal na narrativa

## Evitar

- brasileirismos
- traducoes literais de ingles tecnico em UI quando houver opcao natural em pt-pt
- humor que quebre a atmosfera sem razao

## Tom Narrativo

- frio
- humano
- claustrofobico
- pragmatico
- emocional sem melodrama

## Tom de Interface

- claro
- curto
- sem ambiguidades
- consistente entre botoes, estados e descricoes

## Glossario Inicial

- shelter -> abrigo
- survivor -> sobrevivente
- morale -> moral
- supplies -> mantimentos
- threat -> ameaca
- objective -> objetivo
- event -> evento
- round/turn -> turno

## Processo Editorial

- qualquer conteudo novo deve ser revisto para pt-pt
- termos de jogo devem ser atualizados no glossario quando forem estabilizados
- copy de UI e narrativa nao devem divergir no vocabulario base
