# A Longa Noite

Jogo de browser de sobrevivencia narrativa, inspirado no tipo de tensao, cooperacao e dilemas morais dos survival board games, mas com identidade propria.

## Objetivo do projeto

Criar uma experiencia jogavel no browser, em portugues europeu, com:

- gestao de sobreviventes, abrigo e recursos
- eventos narrativos e escolhas dificeis
- interface rica e atmosferica
- possibilidade de jogo online com amigos
- base de conteudo expansivel

## Estrutura inicial

- `docs/`: visao, roadmap, design e guias editoriais
- `progress/`: tracking do trabalho e decisoes
- `content/`: personagens, eventos e dados de jogo
- `assets/`: registo e organizacao de imagens e video
- `prompts/`: prompts e material de apoio para agentes
- `team/`: papeis, ownership e coordenacao de developers/agentes

## Primeiro foco

O projeto arranca com um `vertical slice`:

- um abrigo
- um conjunto reduzido de sobreviventes
- um tipo principal de inimigo
- eventos narrativos suficientes para testar o ritmo
- uma experiencia local antes de multiplayer
